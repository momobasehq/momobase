# Momobase

[![Go tests](https://github.com/momobasehq/momobase/actions/workflows/tests.yml/badge.svg)](https://github.com/momobasehq/momobase/actions/workflows/tests.yml)
[![Documentation](https://github.com/momobasehq/momobase/actions/workflows/site-pages.yml/badge.svg)](https://momobase.dev/)
[![Release](https://img.shields.io/github/v/release/momobasehq/momobase)](https://github.com/momobasehq/momobase/releases)
[![License](https://img.shields.io/github/license/momobasehq/momobase)](LICENSE.txt)

Momobase is a self-hosted payment orchestration service. It gives applications one API for collections and disbursements, then routes each payment through the provider adapters you register.

[Documentation](https://momobase.dev/) · [Getting started](https://momobase.dev/guide/getting-started) · [API reference](https://momobase.dev/api-reference) · [Releases](https://github.com/momobasehq/momobase/releases)

Installation, configuration, SDK usage, provider development, deployment, and contribution workflows live in the [Momobase documentation](https://momobase.dev/).
