## Overview
Momobase is a self-hosted payment orchestration service. It gives applications one API for collections and disbursements, then routes each payment through the provider adapters you register.

Installation, configuration, SDK usage, provider development, deployment, and contribution workflows live in the [Momobase documentation](https://momobase.dev/).
